# Formline Discord integration

Beta mode; payments disabled. The Cloudflare interaction worker has been uploaded and enabled. Configure the Discord interactions endpoint to `https://formline-discord.formline-app-d6e2.workers.dev/discord/interactions`. Portal: `https://formline-beta.formline-app-d6e2.workers.dev` (not deployed yet). Binding `DB` uses the Formline beta D1 database. The public key and app ID are non-secret. Keep the bot token, OAuth client secret, and licensing secret in private environment/Worker secrets, never in source. Register `/formline` and `/license` with `register-commands.mjs` using a securely configured `DISCORD_BOT_TOKEN` environment variable. Do not register commands until the portal is ready. This module verifies signed Discord interactions and responds privately; automatic approval DMs are handled by the separate beta portal implementation.
